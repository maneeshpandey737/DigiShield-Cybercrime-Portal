# DIGISHIELD (A Cybercrime Complaint Portal) 🛡️💻

DIGISHIELD is an end-to-end web-based cybercrime reporting and monitoring platform designed to streamline digital safety, incident management, and evidence submission.

## 🚀 Key Features
- **Tailored Safety Categories:** Specialized workflows for Kids Protection, Women Safety, and Elders Support (UPI/OTP Fraud Prevention).
- **Anonymous Reporting:** Frictionless complaint filing without mandatory upfront login.
- **Evidence Management:** Upload screenshots, transaction receipts, or PDF proof alongside complaints.
- **Live Status Tracking:** Auto-generates unique Tracking IDs for users to monitor investigation updates.
- **Admin Command Center:** Threat analytics metrics, complaint review panel, and evidence verification system.

## 🛠️ Tech Stack & Architecture
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Java (Servlets & JSP)
- **Database:** MySQL
- **Development Tools:** Apache Tomcat, Eclipse / VS Code
- **Methodology:** Agile Software Development
